#  jjk 的天气预报小助手 (V1.0 基础版)

这是本项目的最初版本，基于 Flask 构建的传统天气预报查询系统。
*(注：项目后续已演进至 V2.0 版本，加入了 AI 问答、RAG 检索与二次元 UI)*

##  核心特性 (V1.0)

- **传统服务端渲染 (SSR)**：前端采用 HTML `<form method="POST">` 提交表单，后端使用 Flask 接收后，通过 Jinja2 模板（如 `{% if result %}`）将数据重新渲染到页面上。
- **高德天气 API 接入**：实时查询指定城市的天气状况、温度与湿度。
- **基础字典缓存**：写了简单的 `CACHE_TTL=600` 逻辑，防止在短时间内频繁调用高德 API 导致额度耗尽。
- **本地 txt 历史记录**：用 Python 原生的 `with open()` 将查询记录追加写入到本地的 `.txt` 文件中。

##  踩坑与复盘记录 

1. **API Key 泄露危机**：刚学的时候把 API Key 硬编码直接传到了 GitHub，后来被提醒不安全，将整个仓库删了重建，这才学会了用 `.env` 和 `.gitignore`。
2. **`FileNotFoundError` 精准打击**：在读历史记录 `.txt` 文件时，第一次跑找不到文件报错。后来学会了用 `try...except FileNotFoundError:` 来兜底，不再让程序直接崩溃。
3. **页面刷新体验极差**：由于用的是 POST 表单提交，每次查完天气页面都要刷新一次，有点麻烦。

##  技术栈
- **后端**：Python 3, Flask
- **前端**：HTML5, 原生 CSS, Jinja2 模板引擎
- **第三方 API**：高德天气 API
